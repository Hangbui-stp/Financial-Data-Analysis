# Financial Data Analysis with Vietstock

A financial data analysis project using data collected from Vietstock to evaluate the financial performance of Vietnamese listed companies through Microsoft Excel.

## Overview

This repository contains raw financial statement data downloaded from Vietstock and Excel-based analyses for selected listed companies.

## Data Source

- **Source:** Vietstock
- **Coverage:** Annual and quarterly financial statements of Vietnamese listed companies.

## Repository Structure

```
.
├── QUARTERLY_raw/          # Raw quarterly financial statements
├── YEARLY_raw/             # Raw annual financial statements
├── 30firms.xlsx            # Financial data of selected companies
├── Sectorwise_Tariff_Election_Impact.xlsx
├── Top50_Tariff_Election_Impact.xlsx
└── Final FDA 2025 Spring.Rmd
```

## Tools

- Microsoft Excel
- R Markdown
- Vietstock financial data

## Key Tasks

- Collect financial statement data from Vietstock.
- Organize annual and quarterly datasets.
- Perform descriptive financial analysis in Excel.
- Compare financial performance across companies and sectors.
